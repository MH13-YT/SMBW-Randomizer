# 🔧 Interface de Configuration (GUI)



<figure><img src="../.gitbook/assets/Capture d&#x27;écran 2024-04-01 041123.png" alt=""><figcaption><p>Interface Graphique de SMBW_Randomizer</p></figcaption></figure>

Les éléments encadrés (de différentes couleurs) correspond aux éléments cliquable dans l'interface\
\
Chaque module a : \
<mark style="color:red;">**Une Checkbox**</mark>** :** Permet d'Activer ou Désactiver un Module : Coché = Actif\
<mark style="color:blue;">**Une Liste**</mark>** :** Permet de sélectionner un profil de randomisation\
\
En bas de la fenêtre : \
<mark style="color:orange;">**Le Bouton**</mark>** :** Permet de Sauvegarder et lancer le programme en incluant des mods (si le dossier mods existe et que les mods sont au bon format\
<mark style="color:green;">**Le Bouton**</mark> **:** Permet de Sauvegarder et lancer le programme
