# Random Areaparam

Le fichier gérant la sécurité de Level Order est stocké sous le nom data\_config.json dans le dossier du module random\_areaparam

les entrées correspondent aux identifiants des différentes zone des niveaux et chaque entrée a huit options\
Pour savoir quel niveau correspond a quel id vous pouvez utiliser la page suivante du Wonderwiki :\
[https://shibbo.net/WonderWiki/index.php/Filesystem/romfs/BancMapUnit](https://shibbo.net/WonderWiki/index.php/Filesystem/romfs/BancMapUnit)
