# Level Order

Le fichier gérant la sécurité de Level Order est stocké sous le nom data\_config.json dans le dossier du module level\_order\
\
les entrées correspondent aux identifiants des niveaux et chaque entrée a deux options\
\
Pour savoir quel niveau correspond a quel id vous pouvez utiliser la page suivante du Wonderwiki :\
[https://shibbo.net/WonderWiki/index.php/Filesystem/romfs/BancMapUnit](https://shibbo.net/WonderWiki/index.php/Filesystem/romfs/BancMapUnit)\


<table><thead><tr><th width="179">Nom de l'entrée</th><th>Description</th></tr></thead><tbody><tr><td>enabled</td><td>active la randomisation du niveau (Le niveau sera changé de place)</td></tr><tr><td>hasSecretExit</td><td>est ce que le niveau a une sortie secrete ?</td></tr></tbody></table>
