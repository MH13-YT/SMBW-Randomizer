## Présentation du Projet

Ce projet est un programme python permettant a partir de la ROMFS du jeu de rendre aléatoire divers éléments du jeu

> Actuellement les éléments randomisable sont :\
> \- L'emplacement des niveaux sur la carte\
> \- Le badge selectionné dans chaque niveau\
> \- Les effets des différentes fleurs Wonder\
> \- Les Ennemis dans les niveaux\
> \- Les Ressources de chaque niveaux (Musique, Arriere Plan ...)

> Les éléments ci dessus sont géré par un module distinct pouvant etre activé ou désactivé et chaque module comporte de multiple profils (permettant de parametrer en profondeur la randomisation)
