# 🐞 Déclarer un Bug de Randomisation ou suggerer une nouvelle fonctionnalité

## Rédaction du formulaire de traitement de bug

{% hint style="danger" %}
Comme mentionné sur le formulaire, veuillez ne pas ecrire d'issue si cela concerne une utilisation avec un mod\
\
Les profils sécurisé sont conçus pour une utilisation sur le jeu d'origine, tout bug report relatif a une utilisation moddé sera automatiquement rejeté

\
Cela s'applique aussi si vous avez utilisé des profils non intégré a la liste
{% endhint %}

{% hint style="info" %}
Veuillez remplir le formulaire en incluant le plus de détails possible pour permettre au contributeurs de traiter votre bug plus facilement\
\
Vous pouvez utiliser le fichier latest.log et des vidéos YouTube (en lien only) pour illustrer votre bug
{% endhint %}

## Procédure de traitement de votre issue

{% hint style="warning" %}
Les étapes 3 et 4 sont spécifique au traitement de Bug de randomisation\
\
Si votre suggestion est accepté les étapes 3 et 4 seront aussi réalisé
{% endhint %}

Votre issue est traité en différentes étapes, vous pouvez suivre son état a partir des label choisi\
\
1 : Correspond au prétraitement de votre issue (Verifie le contenu)\
2 : Correspond au traitement par un contributeur (Est ce qu'un contributeur travaille dessus)\
3 : Correspond a l'état du traitement (Recherche / Developpement / Test / Pret au Deploiement)\
4 : Correspond a l'état du déploiement dans la release (Déployé ou non)
